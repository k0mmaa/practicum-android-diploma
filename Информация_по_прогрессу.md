## 2. Выполненные требования

### 2.1. Общие требования к приложению — **выполнено**

- **Минимальный SDK 26** (Android 8.0): `minSdk = 26` в `libs.versions.toml`.
- **Иконка приложения** создана из изображения из макета.
- **Цветовая палитра светлой и тёмной темы** по макету: `colors.xml`, `values/themes.xml`, `values-night/themes.xml`.
- **Ориентация `portrait`** зафиксирована в манифесте.
- **Single Activity + Jetpack Navigation Component**: `RootActivity` + `NavHostFragment` + `nav_graph.xml`.
- **Переходы через `NavController` и `BottomNavigationView`**: `setupWithNavController`.
- **Чистая архитектура**: слои `data` / `domain` / `ui` (`presentation` пока заготовка).
- **Сетевые запросы через Retrofit**: `JobsApiService`, `JobsApiClient`.
- **Проверка подключения к интернету перед запросом**: `CheckNetwork` / `CheckNetworkImpl`.
- **Обёртка `Resource` для ответов**: `util/Resource.kt`.
- **Koin, модули разделены по слоям**: `networkModule`, `dataModule`, `repositoryModule`, `interactorModule`.
- **Цвета, размеры, строки вынесены в `values`**: `colors`, `dimens`, `strings`, `styles`.
- **ViewBinding** используется в `RootActivity`.

### 2.2. Эпик 0 — **выполнено**

- **`build.gradle` и манифест** скорректированы:
    - зависимости: Retrofit, Room, Glide, Koin, Navigation, корутины;
    - манифест: `App`, тема, разрешения, ориентация.
- **Иконка** создана.
- **Структура пакетов** создана.
- **Data-слой и БД**:
    - DTO, API, NetworkClient, репозиторий, интерактор;
    - Room: `AppDatabase`, `VacancyEntity`, `VacancyDao`, конвертеры, маппер.
- **Вспомогательные классы**: `Debounce`, `CheckNetwork`, `Resource`.
- **DI**: Koin-модули, инициализация в `App`.
- **Темы и стили**: светлая и тёмная темы, шрифты YS Display, стили текста, кнопок и нижней панели.
- **BottomNavigationView**: три вкладки, переключение экранов.
